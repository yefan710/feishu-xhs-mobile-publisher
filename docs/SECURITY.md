# 安全与部署边界

## 私有配置

- `.env`、`data/`均被Git忽略，public只挂载`public/`目录，不能将仓库根目录作为静态网站。
- 飞书secret只在服务器读取，用于获取应用token。异常不输出Axios请求对象/headers，读表检查只输出计数。
- 工作台密码加盐scrypt，JWT12小时。禁用/删除账号和更换其密码会通过authVersion校验撤销旧会话。没有通用默认生产密码。
- 演示账号仅用于本机合成数据；模拟文件位于临时目录。不将DEMO_MODE暴露为正式站点。
- Linux私有目录应700、配置600；容器默认非root uid1000。Windows使用当前用户文件ACL保护私有配置。备份也要保护。

## 公开图片的特殊权限

App无法发送网页登录JWT，因此图片端点公开，但仅接受48hex随机凭证、合法序号、有效期。**知道URL的人在有效期内能读图片**，这不是每次鉴权的用户私有文件。不要把链接发到公开日志、群消息、搜索索引或第三方统计；不要把图片当成永久公开素材。

网页Referrer策略和图片响应避免传出token；默认代理示例关闭access日志。若必须开启访问日志，请对`/api/queue/media/`路径隐去随机token。audit只保存actor、record_id、JW、账号、状态和时间，它仍是业务私有日志，不提交Git。自行配置轮转与保留期。

不把整个`data/media`静态暴露，不用可预测的record_id做公开图片口令。HTTPS证书必须可信；不要绕过证书警告。缓存超过TTL立即不可读，磁盘删除在下次清理时完成。

## 账号与网络

所有工作台用户共享同一张配置表的素材范围，账号筛选不是权限隔离；不适合作为陌生用户公共SaaS。不同朋友各自部署自己的表格。要隔离多人，必须服务端对list/prepare/status都做授权，不能只改网页。

登录限制每IP15分钟30次；生产必须正确设置反向代理信任。默认trust proxy=loopback，Compose仅使用一个可信入口，app端口仅绑定localhost。不要把TRUST_PROXY设为全信任，再直接公网暴露3000；代理应覆盖用户伪造的转发头。

网页JWT保存在localStorage，所以同源XSS会影响会话。静态资源使用CSP、自托管JS、不执行表格中的HTML，正文通过textContent显示。不要往网页加入未知统计脚本或宽松跨域；定期更新依赖并执行npm audit。

## 操作一致性

状态快照检查与进程内锁降低误写，不是飞书端事务。同一记录应避免多方同时编辑；单实例运行。自动回写只改变指定record_id的单选状态。点击规则不能视为实际发表证据；失败后恢复状态并人工复核。

代理之外没有WAF、资源配额或存储容量上限：服务只允许可信发布人员登录，按图片规模监控磁盘与公网流量。公开图片请求会消耗带宽，泄露链接后可删除对应任务或等待过期。不要把广泛管理权限开放给不受信任用户。

## 发布开源仓库前

只提交源码、空模板、锁文件、部署样例、合成fixture和文档。排除账号哈希、密钥、真实AppID/BaseID、真实素材、测试快照、audit、个人路径、服务器地址、SSH信息。检查Git暂存清单与内容，再推送。根LICENSE与NOTICE保留第三方来源。
